# NARU 시각 레퍼런스

| 상태 | 이미지 | 참고 범위 |
| --- | --- | --- |
| 현재 목표 | [겨울 하츠모데 · 사용자 제공 2번 이미지](naru-hatsumode-winter-reference.png) | 방문객 눈높이의 광각 구도, 도리이와 참배로, 좌우 건축과 숲의 깊이, 블루아워 노을, 황금빛 등불, 눈이 쌓인 표면 |
| 초기 기록 | [기존 나루 메인 화면](naru-main-reference.png) | 초기 광장 디자인을 확인하는 자료 |

두 이미지는 디자인 검토용이다. 현재 목표 이미지의 인파·다리·수경은 별도의 기능 요구로 해석하지 않는다. 사용자 제공 이미지의 제작자와 라이선스는 확인이 필요하다. 팀 검토용 레퍼런스로 보관하며 서비스 배경과 배포 에셋으로 사용할 경우 사용 권한을 먼저 확인한다. 아트 디렉션과 검증 원칙은 [공통 AI 개발 지침](../../AGENTS.md)을 따른다.
